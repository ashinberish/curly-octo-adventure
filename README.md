# Pixel Office

An 8‑bit office you walk around in, where every employee is a Claude agent. Give employees
skills, assign them tasks, and watch them work.

- **Plan:** [docs/PLAN.md](docs/PLAN.md)
- **Mockup:** open [mockup/index.html](mockup/index.html) in a browser. It is a single file with no
  build step, and the agents are simulated.

Mockup controls: `WASD` / arrow keys to walk, `E` to talk to whoever you're next to (or click
them), and the whiteboard opens the task board.
